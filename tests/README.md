# 🧪 DagCity Test Suite

This directory contains the comprehensive test suite for the DagCity project, covering both the Python backend and the JavaScript frontend logic.

## 🏗️ Structure

```text
tests/
├── python/               # Backend Tests (pytest)
│   ├── test_parser.py    # Core dbt manifest parsing logic
│   ├── test_router_projects.py  # Project CRUD API endpoints
│   ├── test_main_endpoints.py    # Global app endpoints (upload, live sync)
│   └── test_watcher.py   # File system watcher & debounce
├── js/                   # Frontend Tests (jest)
│   ├── State.test.js     # Reactive state management
│   ├── dataManager.test.js # File ingestion & SSE routing logic
│   ├── storageManager.test.js # IndexedDB persistence
│   └── parser.contract.test.js # Data contract validation
└── conftest.py           # Shared Python test fixtures
```

## 🐍 Python Tests (Backend)

The backend tests use `pytest` and `httpx` (via FastAPI `TestClient`).

### Prerequisites
Ensure you have the dev dependencies installed:
```bash
pip install pytest pytest-asyncio httpx
```

### Running Tests
Run all backend tests:
```bash
pytest
```

Run a specific test file:
```bash
pytest tests/python/test_parser.py
```

## 🕹️ JavaScript Tests (Frontend)

The frontend tests use `Jest` with a `jsdom` environment.

### Prerequisites
Install the node dependencies:
```bash
npm install
```
*(Includes `jest`, `fake-indexeddb` for storage testing, and `jest-environment-jsdom`)*

### Running Tests
Run all frontend tests:
```bash
npm test
```

Run tests in watch mode:
```bash
npm run test:watch
```
